Анализ лояльности пользователей Яндекс Афиши с помощью Python

Проект направлен на реализацию следующей цели:
Команда маркетинга хочет лучше понимать поведение пользователей. Для этого они просят вас провести исследовательский анализ данных, чтобы понять, какие пользователи с большей вероятностью возвращаются на платформу и делают заказы повторно. Это позволит:
- Быстро выяслять перспективных клиентов и предлагать им персонализированные условия.
- Точно настраивать рекламу на аудитории с высокой вероятностью возврата.
- Оптимизировать макретинговые бюджеты.
- Повысить общий уровень удержания клиентов.

Архитектура проекта:
project/
├── data/               # Датасеты - витрина исследуемых данных и датасет курса тенге к рублю
├── src/                # Скрипты-хелперы для извлечения витрины по запросу, а также авторепорт
├── scripts/            # SQL-скрипты ответы на вопросы перед проектом и выгрузка витрины данных
├── requirements.txt    # Список зависимостей  
├── REPORT.ipynb        # Ноутбук с отчётом  
└── README.md           # Редми-файл (Вы тут :)

Запуск проекта в своем окружении:

1) Создать и запустить окружение 
    cd '***Папка с проектом***'
    python -m venv venv
    source venv/Scripts/activate

2) Установить требуемые зависимости:
    pip install -r requirements.txt

ВНИМАНИЕ! Следующие два шага выполняются в случае, если хотите запустить проект с нуля. Если Вы хотите проверить готовый отчёт, то он с выполненными ячейками хранится в ноутбуке REPORT.ipynb.

3) Если есть необходимость выгрузить витрину данных согласно запросу, необходимо:
    3.1) СОЗДАТЬ новый файл в корне проекта с названием "connection_props.env" и заполнить его СТРОГО в следующем формате:
            db_user=***Имя пользователя***
            db_password=***Пароль***
            db_host=***Имя хоста***
            db_port=***Порт подключения***
            db_db=***Название базы данных***
        Если в одном из полей будет ошибка, скрипт не сработает.
    3.2) Запустить скрипт .src/data.py. После исполнения программы датасет будет автоматически выгружен и сохранён в .data/raw.csv.

4) Зайти в ноутбук: REPORT.ipynb, перезагрузить ядро Kernel и запустить все ячейки.
